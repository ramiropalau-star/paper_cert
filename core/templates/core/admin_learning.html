Aprendizaje del emisor

Herramientas para revisar y corregir lo que el sistema aprendió de los certificados aprobados.

  • Perfiles de formato — anchors y cohortes por entidad/examen/año; desactivar o re-puntuar.
  • Aliases de campos — etiquetas impresas aprendidas; activar, desactivar o rechazar.
  • Verificadores por emisor — reglas de verificación en origen (host, URL, patrones).

Limpieza de falsos positivos: rechazar el certificado en su detalle de revisión, luego reconstruir perfiles con python manage.py rebuild_format_profiles y crear un nuevo golden set con python manage.py evaluate_extraction build-set.
